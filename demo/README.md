# FROSTR Demos

Interactive demonstrations of the FROSTR threshold signing protocol.

## Available Demos

### [tmux/](./tmux/) - Terminal Demo

A multi-pane terminal demo using tmux that runs a local relay and multiple nodes. Great for understanding the protocol flow and testing locally.

```bash
npm run demo
```

See [tmux/README.md](./tmux/README.md) for full documentation.
